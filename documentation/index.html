1. Overview & Key Highlights

Wazzopi is an end-to-end e-commerce solution engineered for specialty coffee roasters, retail brands, and web agencies needing a ready-to-deploy digital storefront.

  • Latest Next.js 15: Powered by modern Server Components, Server Actions, and Streaming.
  • Multi-Language (i18n): Instant language switcher supporting English (Default) and Bahasa Indonesia with cookie persistence.
  • Triple Payment Gateway Architecture: Integrated with PayPal, Stripe (Credit Cards), and Midtrans (Indonesian Local Payment Ecosystem).
  • Automated Shipping Rates: Multi-courier support (JNE, POS, TIKI) via courier API + Flat Rate Shipping.
  • Comprehensive Admin Portal: Inventory management, variant weight pricing, sales charts, coupons, and email notifications.

2. System Requirements

Before installing, make sure your development environment meets the following requirements:

  • Node.js: Version 18.18.0 or 20.x+ recommended.
  • NPM / PNPM / Yarn: NPM v9+ included with Node.
  • Database: SQLite (preconfigured for local zero-setup dev) or PostgreSQL (recommended for production).

3. Local Installation

Follow these quick steps to get Wazzopi up and running on your local machine:

# 1. Unzip the project files and enter directory
cd wazzopi

# 2. Install all dependencies
npm install

# 3. Create your local environment file
cp .env.example .env

# 4. Generate Prisma Client and Push Database Schema
npm run db:push

# 5. Populate sample demo data (Products, Admin User, Orders)
npm run db:seed

# 6. Start development server
npm run dev

Open http://localhost:3000 in your browser to view the live storefront.

4. Database Setup & Seeding

Wazzopi uses Prisma ORM, which makes switching between databases effortless:

Environment Provider Connection Example
Local Dev SQLite file:./dev.db
Production PostgreSQL postgresql://user:pass@host/db?sslmode=require

Resetting or Reseeding Data:

# Populate demo products, users, categories and analytics
npm run db:seed

# Complete fresh database reset
npm run db:reset

5. Multi-Language (i18n) Configuration

Wazzopi includes a modular dictionary-based translation architecture in src/i18n/.

  • Default Locale: English (en). Configured in src/i18n/config.ts.
  • Adding a new language: Simply duplicate src/i18n/dictionaries/en.ts to your desired locale (e.g., es.ts for Spanish) and register it in SUPPORTED_LOCALES.

6. Payment Gateways Setup

You can toggle and configure payment gateways dynamically from Admin Dashboard > Store Settings > Payment Methods:

  • PayPal: Toggle between Sandbox and Live mode, enter your Client ID & Secret from developer.paypal.com.
  • Stripe: Toggle between Test and Live mode, enter Publishable Key & Secret Key.
  • Midtrans: Toggle between Sandbox and Production mode for Indonesian QRIS and Virtual Accounts.
  • Manual Bank Transfer / COD: Customizable instructions and bank account numbers.

7. Deployment to Vercel (1-Click Guide)

Deploying Wazzopi to Vercel is completely free and takes less than 3 minutes:

  1. Push your codebase to a private GitHub repository.
  2. Go to Vercel and click Add New Project > Select your repository.
  3. In the Environment Variables section, provide:
    • DATABASE_URL (Use a free cloud PostgreSQL from Supabase, Neon, or Railway).
    • AUTH_SECRET (A random 32+ character string).
    • NEXT_PUBLIC_APP_URL (Your Vercel URL, e.g. https://your-brand.vercel.app).
  4. Click Deploy. Vercel will automatically run the build and publish your high-performance serverless store.
